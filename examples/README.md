# Example reports

Investigation reports generated by the prototype for the six synthetic scenarios, in English and Italian. Every customer, counterparty, account, and transaction in them is invented; see the disclaimer in the [main README](../README.md).

| Scenario | Story | Expected outcome | English | Italian |
|---|---|---|---|---|
| `fp_salary_bonus` | One-off annual bonus from the usual employer | Close | [report](fp_salary_bonus_en.docx) | [report](fp_salary_bonus_it.docx) |
| `fp_property_sale` | Proceeds from the sale of a flat | Close | [report](fp_property_sale_en.docx) | [report](fp_property_sale_it.docx) |
| `structuring_cash` | Cash deposits just below a threshold | Escalate | [report](structuring_cash_en.docx) | [report](structuring_cash_it.docx) |
| `pass_through` | Money from many people, wired abroad | Escalate | [report](pass_through_en.docx) | [report](pass_through_it.docx) |
| `dormant_reactivation` | Dormant account suddenly moving large sums | Escalate | [report](dormant_reactivation_en.docx) | [report](dormant_reactivation_it.docx) |
| `profile_mismatch` | Sole trader far above the declared turnover | Request more information | [report](profile_mismatch_en.docx) | [report](profile_mismatch_it.docx) |

The reports were enriched by the default backend, a local `llama3.1:8b` served by Ollama; the cover page and the appendix of each report say how many transactions the LLM enriched and how many fell back to the rule-based baseline.

To regenerate them from the committed sample data:

```bash
uv run aml-report examples                       # default backend: local model via Ollama
uv run aml-report examples --enricher baseline   # offline, rule-based only
```
